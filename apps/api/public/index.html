      Why this exists
      
The hour that
cost $5,000

      

        
I found the bug. I wrote it up clean. I hit submit and waited.

        
Behind that one report: hours of research, a proof of concept I got working, and the nights I didn't sleep getting there.

        
It was gone before I sent it. Someone else had filed the same finding hours earlier.

        
The program had opened that morning. I found it hours later. Nothing tells you when a program goes live.

        
The reply came back as one word. Valid. Duplicate.

        
Duplicate is the polite word for: every one of those hours was worth nothing.

        
Same bug. Same severity. Same fix. Five thousand dollars to whoever loaded the page first.

        
I didn't lose to a better hacker. I lost to an hour.

        
So I stopped refreshing. I built Mycelium so that hour never costs me again.
